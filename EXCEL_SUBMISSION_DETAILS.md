# CA1 Mandatory Project Submission Guide (UMS Excel File)

According to **Section 4 of the CA1 Project-Based Assessment Instructions**:
> *"Students must upload one Excel file (`.xlsx`) or doc file on UMS as the Project Submission File."*

We have already created the official Excel file for you:
`CA1_Project_Submission_Sheet.xlsx` located right inside your project folder:
`campus-event-portal/CA1_Project_Submission_Sheet.xlsx`

---

## 📋 Required Table Format (Exact LPU Specification)

| Project Name & Title | Team Name | Course Code | Registration Number(s) | GitHub Link | Deployed Link | Video Presentation Link |
|:---|:---|:---|:---|:---|:---|:---|
| **Campus Event Management & Registration Portal** | *[Your Team Name]* | *[e.g. INT219 / CSE326]* | *[Reg. No. 1, Reg. No. 2, Reg. No. 3]* | `https://github.com/[username]/campus-event-portal` | `https://[username].github.io/campus-event-portal/` | `[Link to Google Drive / YouTube video]` |

---

## 📝 How to Fill and Submit on UMS:

1. Open `CA1_Project_Submission_Sheet.xlsx` in Microsoft Excel, Google Sheets, or LibreOffice.
2. Fill in your:
   - **Team Name**
   - **Course Code** (e.g., INT219, CSE326, etc.)
   - **Registration Number(s)** of all team members
   - **GitHub Repository Link** (ensure repo is **Public**)
   - **Deployed Link** (e.g. GitHub Pages URL: `https://<username>.github.io/campus-event-portal/`)
   - **Video Presentation Link** (ensure permissions are set to *"Anyone with the link can view"* if using Google Drive)
3. Save the file as `.xlsx`.
4. Upload `CA1_Project_Submission_Sheet.xlsx` to the UMS CA1 submission portal before the deadline.
